💡 Background
업무 중 다양한 이슈(예: 버그 리포트, 개선 요청, 사용자 문의 등)가 텍스트 형태로 수집되는데, 이를 정확하게 카테고리화하지 않으면 우선순위나 담당자 지정에 혼선이 생겼습니다.

🔍 Meaning

또한, 모델 정확도를 높이기 위해 다양한 알고리즘을 실험해보고 하이퍼파라미터 튜닝도 적용하면서, 실험적 사고와 분석 역량이 한층 강화되었습니다. 무엇보다 실제 업무 효율 향상에 기여할 수 있었던 점에서 기술의 실용성과 의미를 깊이 있게 느낄 수 있었습니다.

분리배출은 품목마다 기준이 달라 사용자가 매번 정확한 배출 방법을 찾기 어렵습니다.
정형 데이터로 빠르게 카테고리를 예측하는 방식과, 문서 기반 근거를 검색해 답변하는 RAG 방식을 비교·결합하여 더 실용적인 안내 서비스를 만들고자 했습니다.

🔍 Meaning
Flask API에서 /classify와 /classify_llm 엔드포인트를 분리해 ML 예측과 LLM/RAG 응답을 각각 호출할 수 있도록 구성했습니다.
RandomForestClassifier는 waste_train.xlsx 데이터를 기반으로 품목 카테고리를 분류하고, LangChain·ChromaDB 기반 RAG는 waste_train.pdf 문서를 검색해 분리배출 가이드를 생성합니다.

2026.09.10 ~ (개인 프로젝트)

📌 Summary & Key Features
데이터 파이프라인 (Modern Data Stack) 아키텍처 구성
- 가짜 데이터 생성 → DuckDB 적재 → dbt 변환(Staging/Intermediate/Marts) → Streamlit 서빙까지 로컬 환경 내 ELT 파이프라인 구축
- Cosmos 라이브러리를 활용해 dbt 프로젝트를 Airflow DAG 태스크로 자동 변환 및 오케스트레이션

🛠️ TroubleShooting & Deep Dive
1. Fan-out 데이터 중복 집계 결함 탐지 및 구조적 해결
- 문제: 일자·기기별 매출 집계 시, 사용자 로그 데이터 조인 과정에서 1:N 관계로 인한 Fan-out 중복 집계 발생 확인. 원본에 이미 중복 로그가 존재했으나 주문 건과 겹치지 않아 우연히 결과가 맞았던 잠재적 데이터 정합성 결함 탐지
- 검증: 재현 테스트를 통해 특정 일자에서 24,600원의 매출이 과대 계상됨을 데이터로 증명
- 해결: 원본 로그를 `user-day` 그레인(grain) 수준으로 사전 집계하는 Intermediate(중간 계층) 모델을 신설하여 조인 전 중복을 차단하는 구조적 해결 적용

2. 커스텀 Generic Test 기반 데이터 정합성 보장
- 집계 오차가 발생하더라도 주문 건수는 정상값을 유지하고 매출만 부풀려지는 Fan-out의 특성을 고려하여, Mart 집계값과 원본 값을 직접 대조하는 커스텀 Generic Test 구현
- Cosmos가 Singular Test를 DAG 태스크로 자동 생성하지 못해 스케줄러에서 누락되는 이슈를 발견하고, 이를 모델 연결형 Generic Test로 전환하여 Airflow 파이프라인 내 테스트 실행 보장

3. 파이프라인 안정성 및 최적화 강화
- 데이터 품질: unique, not_null, 허용값, 범위 검증 등 데이터 품질 테스트 30개를 파이프라인에 편성. 파싱 실패 유입 데이터는 `warn severity`로 설정해 파이프라인 중단 없이 결함을 감지
- 비용 최적화: Mart 테이블을 증분 모델(delete+insert)로 전환하고 lookback 구간을 재집계하도록 설정하여 지연 도착(Late-arriving) 데이터를 흡수하면서도 전체 테이블 재생성 비용(Full Refresh) 제거
- 락 충돌 방지: DuckDB의 단일 쓰기(Single-write) 제약을 고려해 Airflow의 `max_active_runs`와 `threads`를 제어하여 동시성 충돌 방지 및 `retries`와 `exponential backoff`로 일시적 실패 흡수
- 실행 환경 자동화: DAG, profiles, 스크립트의 절대경로 하드코딩을 제거하고 Makefile 및 requirements.txt를 통해 단일 명령어로 실행 환경이 고정·재현되도록 패키징
